# 📘 Assignment: Python Text Processing

## 🎯 Objective

Build a small text processing tool that reads a file, cleans the text, and produces useful summaries. You will practice string operations, file I/O, and basic text manipulation.

## 📝 Tasks

### 🛠️ Load and Clean Text

#### Description
Read a text file, normalize the content, and prepare it for analysis.

#### Requirements
Completed program should:

- Open and read a text file from disk.
- Convert text to lowercase and remove punctuation.
- Split the cleaned text into a list of words.


### 🛠️ Analyze and Transform Text

#### Description
Compute simple statistics and create a transformed version of the text.

#### Requirements
Completed program should:

- Count total words and unique words.
- Display the most common word and its count.
- Create a new text output where all digits are replaced with `#`.
